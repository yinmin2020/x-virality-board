# yinmin1987 · X Virality Board

Public GitHub Pages dashboard for @yinmin1987's X virality desk. Watches 12 accounts, lists original posts
with >= 5,000 views (stars >= 10,000), mines keywords/topics from them and drafts English post ideas.

- Live: https://yinmin2020.github.io/x-virality-board/
- Data: `data.json` (rendered by `index.html`, no build step)
- Daily refresh: see [REFRESH.md](REFRESH.md)
- Based on the open-source starter https://github.com/monkeyteamvip/x-virality-score (see LICENSE).
- All numbers come straight from the X API (`impression_count`); nothing is estimated.
